If the button does not work, or Outlook refuses the paste: select everything in this box and copy it. For classic Outlook on Windows you can skip pasting altogether — save it as Suder.htm into %APPDATA%\Microsoft\Signatures, naming it exactly as an existing signature there.

Where it goes

Outlook for Windows
  1. File → Options → Mail → Signatures.
  2. Pick your existing signature, or New to add one.
  3. Select everything in the edit box and delete it.
  4. Paste. Use Ctrl+V, not Paste Special — plain text drops the images.
  5. Set it as the default for New messages and Replies/forwards, then OK.
Outlook for Mac and Outlook on the web
  1. Settings → Mail → Compose and reply.
  2. Clear the existing signature, then paste with ⌘V.
  3. Tick the boxes for new messages and replies, then Save.
Gmail
  1. Gear icon → See all settings → General → Signature.
  2. Clear the box, then paste.
  3. Under Signature defaults, set it for new mail and for replies.
  4. Scroll to the bottom and Save Changes — Gmail discards it otherwise.
Apple Mail
  1. Mail → Settings → Signatures.
  2. Untick Always match my default message font, or the formatting is stripped.
  3. Select the account, clear the preview pane, and paste.

Worth knowing

Outlook for Windows does not animate GIFs. It shows the first frame only, which is why the first frame is the settled tagline. Those recipients see a clean static line rather than a reel stopped mid-word.

Dark mode shows a white panel. The tagline and badges carry white backgrounds, so on a dark-themed client they sit on a light rectangle. Email cannot swap images by theme; a dark-background set is the alternative, but it would then look wrong in light mode.

Images load from ssuder.com. Nothing is attached to your messages, so the signature adds no weight — but some recipients block remote images by default and will see the alt text until they allow them.
